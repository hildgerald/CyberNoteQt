GET STARTED

Build it.
Make it yours.

CyberNoteQt is open source and built with C++, Qt 6 and CMake. Clone the repository and build it on a Debian-based Linux system.

LinuxC++Qt 6CMakeMIT
Open GitHub repository ↗
TERMINAL / BUILD FROM SOURCE
# Clone the project
git clone https://github.com/hildgerald/CyberNoteQt.git
cd CyberNoteQt

# Install build dependencies (Kali / Debian)
sudo apt update
sudo apt install qt6-base-dev qt6-tools-dev \
  qt6-tools-dev-tools qt6-svg-dev cmake build-essential

# Configure and compile
cmake -S . -B build
cmake --build build -j"$(nproc)"

# Launch
./build/CyberNotePasQt
Build instructions are based on the current project README. Check GitHub for updates.
