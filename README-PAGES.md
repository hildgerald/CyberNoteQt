# CyberNoteQt — GitHub Pages website

This folder contains a static landing page for [CyberNoteQt](https://github.com/hildgerald/CyberNoteQt).

## Publish with GitHub Pages

1. Download and extract this archive.
2. Copy **the contents** of this folder (`index.html`, `assets/`, `.nojekyll`) into the root of the `CyberNoteQt` repository.
3. Commit and push the files to the `main` branch.
4. Open **Settings → Pages** in the GitHub repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for the Pages deployment to finish in the **Actions** tab.

Expected URL: https://hildgerald.github.io/CyberNoteQt/

## Notes

- The page is static HTML/CSS/JavaScript. No server or build step is required.
- The website is written in English for an international open-source audience.
- The workspace shown in the hero is an illustrative mock-up, not a screenshot of the application.
- Build instructions and feature descriptions are based on the repository README at the time this page was prepared. Keep them synchronized with future releases.
- Google Fonts is used for typography; the page falls back to system fonts if unavailable.
