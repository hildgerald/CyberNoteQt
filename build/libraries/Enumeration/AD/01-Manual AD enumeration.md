# Liste des utilisateurs du domaine
```
net user /domain
```

# Liste des infos et des droits d'un utilisateur du domaine
```
net user jeffadmin /domain
```

# Liste des groupes du domaine
```
net group /domain
```

# Liste des utilisateurs appartenant au groupe du domaine
```
net group "Sales Department" /domain
```
